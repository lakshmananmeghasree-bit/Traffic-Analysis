# 📊 Website Traffic Analysis | Alfido Tech Internship

## 📌 Project Overview

This project focuses on analyzing website traffic event data using Python and Microsoft Power BI as part of **Task 4 of my Data Analytics Internship at Alfido Tech**.

The project explores traffic patterns, event distributions, country-wise activity, and popular content to generate meaningful insights and recommend strategies for improving engagement measurement and conversion tracking.

## 🎯 Objectives

- Analyze website traffic events and engagement patterns.
- Examine pageviews, clicks, and previews.
- Identify countries with the highest event volumes.
- Analyze popular tracks and unique link IDs.
- Create visualizations to communicate key findings.
- Recommend data-driven conversion optimization strategies.

## 📂 Dataset Overview

The dataset contains **226,278 events** recorded between August 19 and August 25, 2021.

| Metric | Value |
|---|---:|
| Total Events | 226,278 |
| Pageviews | 142,015 |
| Clicks | 55,732 |
| Previews | 28,531 |
| Unique Link IDs | 3,839 |
| Analysis Period | August 19–25, 2021 |

## 🔍 Key Insights

- Saudi Arabia recorded the highest event volume, followed by India and the United States.
- "Jalebi Baby" was the highest-volume track.
- Pageviews accounted for 142,015 events, while clicks accounted for 55,732 events.
- The click-to-pageview ratio was 39.2%, and the preview-to-pageview ratio was 20.1%.
- The dataset supports event-level analysis but lacks the identifiers and timestamps required for reliable session-level analytics.

## 💡 Recommendations

1. Implement anonymous user/session identifiers and event timestamps.
2. Capture referrer information, UTM parameters, and landing-page URLs.
3. Establish a measurable conversion funnel from content views to CTA clicks and conversions.
4. Improve calls to action and navigation on high-volume content pages.
5. Introduce A/B testing for CTA placement, forms, navigation, and page speed when sufficient tracking data is available.
